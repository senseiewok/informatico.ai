## How to Open Every File Format in Free Tools

- **`.glb` (Khronos glTF 2.0 Binary):** Open in **Blender 4.2+** (`File -> Import -> glTF 2.0`) or inspect directly in the browser on `/toolchain/x01/`–`/toolchain/x07/`.
- **`.step` (ISO 10303-21 AP242 B-Rep Solid):** Open in **FreeCAD 1.0** (`File -> Open`) or **build123d / CadQuery** to inspect `CLOSED_SHELL` faces and millimeter units.
- **`.3mf` (3MF Core v1.2.3 Package):** Open in **OrcaSlicer** or **PrusaSlicer** (FOSS under AGPL-3.0) (`File -> Import -> Import 3MF/STL`) with millimeter units and zero non-manifold edges.
- **`.dxf` (Clean-Room ASCII DXF R2000 Layered 2D CAD):** Open in **QCAD**, **LibreCAD**, **Inkscape**, or **LaserWeb**; `CUT` (perimeter), `MOUNTAIN` (dashed fold), and `VALLEY` (dash-dot fold) layers map directly to laser/CNC toolpaths.
