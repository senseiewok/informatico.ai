4. **Portable Agent Skill (`SKILL.md`)** (`skills/toolchain/x01..x07/SKILL.md`) — cross-provider AI skill with `security-runtime` guardrails.
5. **One-Command Runner** (`python toolchain/run_all_toolchain.py`) — runs all 7 generators, byte-level verifiers, and claim gates in `< 1s`.
