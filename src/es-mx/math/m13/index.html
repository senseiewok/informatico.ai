Act I — Cool Fact & Human Story: Five Confusable Letters on a Pentagon Dial

In autumn 1956, at Bell Laboratories in Murray Hill, Claude Shannon sketched a puzzle around a simple five-letter telegraph dial. Suppose five symbols sit in a ring, and transmission blurs each letter into its two nearest neighbors. If you send one letter at a time, at most two symbols remain completely safe from confusion. Pairing two letters might seem able to double those safe choices from two to four. Yet Shannon noticed five two-letter pairs that stay mutually distinct even under neighbor blur. That single extra message raised the zero-error rate above two per use. For twenty-three years, nobody knew whether longer blocks could beat the square root of five, or how to place an upper ceiling on the ring. Today that same gap still blocks mathematicians on a seven-letter dial, where the true limit remains unsolved.

Su cono igualó el código de cinco pares y cerró el anillo de cinco letras. No obstante, en un anillo de siete letras persiste una pequeña brecha entre los mejores códigos hallados por computadora y ese techo superior.

Shannon formalized this packing problem in his 1956 paper on zero-error capacity (DOI DOI 10.1109/TIT.1956.1056798 [Scite ↗]). Two input symbols share an edge in the confusability graph whenever a channel can turn both into the same received output. Sending blocks of length k without error means picking vertices in the k-fold strong product graph so that no two chosen words differ only by confusable neighbors in every slot. On the five-cycle, pairing two slots lifts the maximum safe set from two to five words. Two decades later, László Lovász (1979, DOI DOI 10.1109/TIT.1979.1055985 [Scite ↗]) constructed an orthonormal cone representation in Euclidean space that squeezed the five-cycle capacity between the five-pair code and an identical geometric ceiling.

That geometric ceiling looked so clean that Lovász wondered whether his theta function might equal zero-error capacity on every graph, and whether capacity always multiplied across separate graphs. Months later, Willem Haemers (1979, DOI DOI 10.1109/TIT.1979.1056027 [Scite ↗]) answered both questions negatively using an algebraic matrix rank bound on twenty-seven lines of a cubic surface. Grötschel, Lovász, and Schrijver (1981, DOI DOI 10.1007/BF02579273 [Scite ↗]) later showed that Lovász theta can be computed in polynomial time by the ellipsoid method, even while exact independence and capacity stay computationally intractable. Meanwhile, Bohman and Holzman (2003, DOI DOI 10.1109/TIT.2002.808128 [Scite ↗]) raised lower bounds on the complements of odd cycles, while Vesel and Žerovnik (2002, DOI DOI 10.1016/S0020-0190(01)00229-0 [Scite ↗]) and Polak and Schrijver (2019, DOI DOI 10.1016/j.ipl.2018.11.006 [Scite ↗]) pushed up the lower bound on the seven-cycle without reaching Lovász theta.

## The governing relation
`α(G) ≤ Θ(G) ≤ ϑ(G) ≤ α*(G) ≤ χ̄(G) · ϑ(C_n) = n cos(π/n) / [1 + cos(π/n)]`

## Rules the essay derives
1. Model zero-error k-symbol block codes as independent sets in the strong product G^{oxtimes k}, never the Cartesian box product, so symbol confusability across simultaneous coordinates is captured.
2. Enforce the Lovasz sandwich alpha(G) <= Theta(G) <= vartheta(G) <= alpha*(G) <= chi_bar(G) and compute odd-cycle theta values via n * cos(pi/n) / (1 + cos(pi/n)).
3. Never treat vartheta(G) as equal to Theta(G) in general: check algebraic minrank bounds such as Haemers rank(A(S_bar) - I) = 7 < 9 = vartheta(S_bar) on the 27-vertex Schlafli complement.
4. Keep Theta(C_7) explicitly labeled OPEN between the verified lower floor 367^(1/5) (~3.257866) and the Lovasz upper bound vartheta(C_7) (~3.317667).

## How it works, in four stages
- Stage 1 (Confusability Graphs and Strong Products, Shannon 1956): Claude Shannon (DOI 10.1109/TIT.1956.1056798) modeled a noisy discrete channel as a graph G whose vertices are input letters and whose edges connect pairs that can produce the same output. Zero-error words of length k form an independent set in the k-fold strong product G^k, yielding Θ(G) = sup_k α(G^k)^(1/k). For C_5, α(C_5) = 2, whereas the five pairs (i, 2i mod 5) form an independent set in C_5^2, giving Θ(C_5) ≥ √5.
- Stage 2 (Lovász Orthonormal Umbrellas and Sandwich Inequality, 1979): László Lovász (DOI 10.1109/TIT.1979.1055985) defined ϑ(G) by placing unit vectors u_i in Euclidean space so non-adjacent vertices are orthogonal, minimizing max_i 1/(c · u_i)^2 over unit handles c. Because ϑ is multiplicative under strong products, α(G) ≤ Θ(G) ≤ ϑ(G) ≤ α*(G) ≤ χ̄(G). On odd cycles, ϑ(C_n) = n cos(π/n) / [1 + cos(π/n)], pinning Θ(C_5) = √5 ≈ 2.236068 via the 3D umbrella cos²φ = 1/√5.
- Stage 3 (Haemers Minrank Separation on the Schläfli Complement, 1979): Willem Haemers (DOI 10.1109/TIT.1979.1056027) bounded Θ(G) above by the minimum rank of any matrix fitting G over a field. On the 27-line cubic-surface intersection graph S_bar = SRG(27, 10, 1, 5), spectrum {10^1, 1^20, (-5)^6} gives ϑ(S_bar) = 9, whereas A(S_bar) − I fits S_bar with exact rational rank 7. Thus Θ(S_bar) ≤ 7 < 9, and the diagonal in S ⊠ S_bar shows Θ(S ⊠ S_bar) ≥ 27 > 3 × 7 ≥ Θ(S) Θ(S_bar).
- Stage 4 (Open Hypothesis on C_7, Tier T0–T1 Bounds, and Falsification Condition): For the seven-cycle C_7, Polak & Schrijver (2019, DOI 10.1016/j.ipl.2018.11.006) found 367 independent vertices in C_7^5, establishing Tier T0/T1 bounds 367^(1/5) ≈ 3.257866 ≤ Θ(C_7) ≤ ϑ(C_7) ≈ 3.317667. Whether Θ(C_7) equals ϑ(C_7) or stays strictly below it remains OPEN. Any strict algebraic upper bound below 3.317667 refutes equality Θ(C_7) = ϑ(C_7), while any block code with α(C_7^k)^(1/k) > 3.257866 tightens the lower floor.

def cycle_distance(a: int, b: int, n: int) -> int:
    diff = (a - b) % n

def is_strong_product_independent(n: int, codewords: tuple[tuple[int, int], ...]) -> bool:
    """Verify pairwise non-adjacency in C_n^{\boxtimes 2}."""

    """Exact Gaussian elimination rank over Q using Python's fractions.Fraction."""
    n = len(matrix)
    m = [[Fraction(val) for val in row] for row in matrix]
    rank = 0
    for col in range(n):
        pivot = next((r for r in range(rank, n) if m[r][col] != 0), None)
        if pivot is None:
            continue
        m[rank], m[pivot] = m[pivot], m[rank]
        inv = Fraction(1) / m[rank][col]
        m[rank] = [x * inv for x in m[rank]]
        for r in range(n):
            if r != rank and m[r][col] != 0:
                factor = m[r][col]
                m[r] = [m[r][c] - factor * m[rank][c] for c in range(n)]
        rank += 1
    return rank


def verify_haemers_schlafli_separation(planted_defect: bool = False) -> dict[str, Any]:
    """Construct the 27-vertex intersection graph S_bar of the 27 lines on a cubic surface
    and verify SRG(27, 10, 1, 5), spectrum {10^1, 1^20, (-5)^6}, vartheta(S_bar) = 9,
    exact rank_Q(A(S_bar) - I) = 7, and non-multiplicativity Theta(S x S_bar) >= 27 > 21.
    """
    verts = (
        [("a", i) for i in range(6)]
        + [("b", i) for i in range(6)]
        + [("c", i, j) for i in range(6) for j in range(i + 1, 6)]
    )
    n = len(verts)

    def lines_meet(u: tuple[Any, ...], v: tuple[Any, ...]) -> bool:
        if u == v:
            return False
        tu, tv = u[0], v[0]
        if (tu, tv) == ("a", "b") or (tu, tv) == ("b", "a"):
            return u[1] != v[1]
        if tu in ("a", "b") and tv == "c":
            return u[1] in (v[1], v[2])
        if tu == "c" and tv in ("a", "b"):
            return v[1] in (u[1], u[2])
        if tu == "c" and tv == "c":
            return len({u[1], u[2], v[1], v[2]}) == 4
        return False

    adj_sbar = [[1 if lines_meet(verts[i], verts[j]) else 0 for j in range(n)] for i in range(n)]
    if planted_defect:
        adj_sbar[0][1] = 1 - adj_sbar[0][1]
        adj_sbar[1][0] = adj_sbar[0][1]

    degrees = sorted({sum(row) for row in adj_sbar})
    lam_set = sorted(
        {
            sum(adj_sbar[i][k] * adj_sbar[j][k] for k in range(n))
            for i in range(n)
            for j in range(i + 1, n)
            if adj_sbar[i][j] == 1
        }
    )
    mu_set = sorted(
        {
            sum(adj_sbar[i][k] * adj_sbar[j][k] for k in range(n))
            for i in range(n)
            for j in range(i + 1, n)
            if adj_sbar[i][j] == 0
        }
    )

    b_mat = [[adj_sbar[i][j] - (1 if i == j else 0) for j in range(n)] for i in range(n)]
    fits_graph = all(b_mat[i][i] != 0 for i in range(n)) and all(
        b_mat[i][j] == 0 for i in range(n) for j in range(n) if i != j and adj_sbar[i][j] == 0
    )
    exact_rank = _exact_fraction_rank(b_mat)

    theta_sbar = 9.0
    theta_s = 3.0
    s_triangle_independent_in_s = (
        adj_sbar[0][7] == 1 and adj_sbar[0][12] == 1 and adj_sbar[7][12] == 1
    )
    diag_product_size = n

    srg_ok = degrees == [10] and lam_set == [1] and mu_set == [5]
    haemers_ok = (
        srg_ok
        and fits_graph
        and exact_rank == 7
        and exact_rank < theta_sbar
        and s_triangle_independent_in_s
        and diag_product_size > theta_s * exact_rank
    )
    return {
        "vertices": n,
        "degrees": degrees,
        "lambda": lam_set,
        "mu": mu_set,
        "vartheta_sbar": theta_sbar,
        "vartheta_s": theta_s,
        "haemers_rank_bound": exact_rank,
        "product_diagonal_lower_bound": diag_product_size,
        "product_upper_product_bound": int(theta_s) * exact_rank,
        "haemers_ok": haemers_ok,
    }
