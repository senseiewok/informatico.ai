# Contributing Policy — Single-Maintainer Verification Ledger

`senseiewok/informatico.ai` is an open-source, read-only public monograph and cryptographic publishing proof archive maintained exclusively by **`@senseiewok`**.

## Pull Request Policy (Owner Only)

- **External pull requests are disabled and not accepted.** Only `@senseiewok` may open, review, or merge pull requests in this repository.
- GitHub repository interaction limits (`collaborators_only`) and `.github/workflows/lock-external-prs.yml` automatically close and lock any pull request or issue opened by accounts other than `@senseiewok`.
- You are welcome to fork or clone this repository under its dual `MIT` (code) and `CC-BY-4.0` (editorial prose & interactive plates) licenses to run the 48 `SKILL.md` verifiers (`python skills/verify_all_48_folios.py`) and Grand-Challenge bounty harnesses (`python bounties/run_all_bounties.py`).
